# 本地处理与限制

全站输入与处理策略集中在 `app/lib/resource-limits.ts`。限额用于避免单次任务耗尽浏览器资源，不代表 Cloudflare 上传配额；本地处理工具不会因为导入大文件而上传原文件到服务器。

## 本次调整

| 处理类型 | 当前策略 |
| --- | --- |
| 视频、音频格式转换与压缩、视频水印与倒放 | 单文件 2 GiB，基于 Blob 按需读取；输出使用有预算的分块 Blob，避免连续大 ArrayBuffer |
| 音频变速、音频倒放、音频裁剪拼接 | 源文件／批量总计 512 MiB，最多 200 段；解码前后检查采样量，不再统一设置 10／30 分钟上限 |
| 图片编辑、压缩、转换、裁剪、水印、像素画、取色等 | 单张 100 MiB、最高 1 亿像素；高像素先提示确认，不自动降低原尺寸导出质量 |
| 图片批量转换／拼接／压缩 | 最多 200 张；转换总计 1 GiB；合成 GIF 总计 512 MiB，逐张解码并释放 |
| 图片 OCR | 100 MiB、1 亿像素；识别用图最长边 6000px，原文件不改变；小字建议裁剪后识别 |
| 贴图通道打包 | 输出宽高最高 8192px，按设备与来源数量检查预计工作空间；栅格数据传递给 Worker 时移交缓冲，避免重复复制 |
| 视频转 GIF | 最长 60 秒，提供最高 1920px、30 FPS；同时检查尺寸 × 帧数的组合计算量，超预算会提示降低参数 |
| Word／PDF 转换 | 200 MiB、文字模式 1000 页；保留版式模式 200 页；DOCX 展开体积保护 512 MiB |
| PDF 页面管理 | 100 个文件、总计 200 MiB、单文件 1000 页、输出 2000 页；列表分页，选中页才渲染预览 |
| ZIP、批量重命名 | 最多 2000 条，总计 512 MiB；解压后总计 512 MiB、单条 256 MiB；保留路径、CRC、压缩比、加密与 ZIP64 检查 |
| Unity 资源包 | 压缩包 512 MiB、流式展开最多 1 GiB、单资源 256 MiB、20000 项资源；树状目录按可见行渲染，搜索保留父级路径，文本仅预览前 1 MiB，下载保留全部内容；严格 TAR 校验，取消时终止后台 Worker |
| 纯文本编辑／格式转换 | 文件 32 MiB；编辑器 800 万字符，格式转换 500 万字符；超限不静默截断文件或粘贴内容 |
| JSON／Markdown／文本对比 | JSON 500 万字符，Markdown 200 万字符，对比两侧合计 200 万字符；JSON 和差异计算在 Worker 执行 |
| Unicode／字幕 | Unicode 10 万个码点、字幕 5 万条；结果分页，导出仍包含完整结果 |
| 3D 模型 | 单文件 512 MiB，转台增加 4K 导出选项；实际可用性仍受模型复杂度、GPU 与编码器影响 |
| 科学计算 | 公式 2000 字符，矩阵最高 12×12，统计 10 万项；保留复杂度、结果长度、取消与超时保护 |
| 抽签 | 最多 5000 项，单项 200 字；CSV／Excel 同步放宽至 5000 项、1000 列、100 万个单元格；Excel 展开体积保护 128 MiB，随机算法与重复选项概率保持不变 |
| 文件哈希 | 原本已分块计算，不增加文件大小上限，也不套用整文件解码警告 |

UI 中 MB／GB 的提示沿用原有习惯，实际字节阈值按 MiB／GiB 计算。限制不是性能保证：设备、浏览器版本、编码器和输入结构都会影响实际可处理规模。

## 内存保护与交互

- 大量文件、单个大文件会先显示“继续导入／取消”，不直接按旧门槛拒绝；手机和低内存设备更早提示。
- 图片先检查可识别的格式头，超过 1 亿像素拒绝；大图显示估算的单份像素缓冲大小，再由用户确认是否按原尺寸处理。
- 需要像素缓冲的图像／贴图操作按预计工作空间检查：桌面 2 GiB、移动端／低内存设备 512 MiB。导入上限不等于每台设备均能处理对应原尺寸。
- 整段音频需要解码为浮点采样，桌面预算为 1.92 亿采样值，移动端／低内存设备为 6400 万；声道、采样率、已有片段都会计入。估算与实际解码结果分别检查。变速工具也检查预期输出采样量。
- 媒体输出按位置写入分块 Blob，支持容器回写文件头。桌面下载缓冲预算 1 GiB，移动端／低内存设备 512 MiB；超预算明确报错，不返回不完整文件。
- 文本、Unicode、PDF 等大列表每页 200 项。长时间本地文件和栅格 Worker 的超时调整为 15 分钟，仍可取消；OCR 为 10 分钟。

## 保留的约束

新增实用工具沿用本地处理原则：密码最长 256 字符、批量最多 1000 条；JWT 最多 10 万字符；正则测试文本最多 200 万字符，独立线程 5 秒后终止，最多列出 1000 个匹配。ICO 输入沿用现有图片限制，输出采用 ICO 标准内的 16–256px 尺寸。详细说明见 [实用工具选型](pc-tool-research.md)。

第二批的图片调色沿用图片输入、像素和栅格工作空间保护；1280px 预览不影响原尺寸导出。DPI 工具只改元数据、不解码像素，输入为 100 MB；支持 1–65535 DPI，超过 10 万结构段视作异常。视频取帧沿用 2 GB 输入，单次最多 200 张；实际输出预算为桌面 512 MiB、手机/低内存设备 256 MiB，不以源视频大小代替解码或输出预算。

第三批文本编解码输入为 200 万字符，拼音为 20 万字符；CSV / TSV / JSON 输入为 500 万字符、10 万行、1000 列、100 万单元格。三者不上传、不保存输入；输出上限 3200 万字符，界面仅预览前 5 万字符，复制和下载保留全部。表格预览单独限制为 101 行、20 列、每格 300 字符，不影响转换结果。图片转 PDF 支持 200 张、每张 100 MB、总计 1 GiB、每张 100 MP；按顺序解码和释放位图，累计嵌入工作量保护为桌面 512 MiB / 移动端 256 MiB，最终 PDF 上限 200 MiB。大批量建议手动选择 2048 / 4096px 或分批，绝不静默降低质量。

浏览器画布、WebGL 纹理尺寸、编码器支持、QR 容量、文件系统名称长度、日期合法范围，以及数学算法的支持范围，不能仅靠提高数字消除。视频倒放仍有 1 小时任务保护，GIF 仍有组合工作量保护。

服务器请求长度、允许的媒体域名、短链接频率限制、ZIP 路径与压缩炸弹保护、HTML 净化及 JSON 嵌套检查不因本次放宽而删除。Cloudflare 单个部署静态资源的限制也与用户本地文件大小无关。

处理限制与发布版本分别管理；调整限制不会自动修改版本号，部署与 GitHub 发布按明确请求执行。

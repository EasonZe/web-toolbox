# 本地处理与限制

图片圆角、画布、双色调和锐化只处理本地静态图片，沿用 100 MiB / 100 MP 源文件检查，输出最长边 8192px、PNG 最多 100 MiB；提前拒绝已识别的动画容器，不静默仅取首帧。圆角和画布按原图、输出画布及编码缓冲联合估算。双色调按 5 份 RGBA8、锐化按 12 份等价缓冲估算，桌面 2 GiB、移动 / 低内存设备 512 MiB，不新增固定 16 / 32MP 限制。设备标记从主线程传入效果 Worker，与 Worker 自身判断取更严格值，以覆盖桌面 UA 的 iPad。四工具只有预览使用缩略图，下载不自动缩图；相关依据见 [图片工具补充](phototool-tools.md)。

OCR 新引擎使用 CPU 单线程 WASM；工作图桌面最多 1600 万、移动 / 低内存 800 万像素、最长边 6000px，先裁剪后放大或缩放，并显示实际工作图尺寸。原始文件上限不变；模型首次按需加载、任务 10 分钟且可终止。中文间距整理保留原始结果，不自动改动英文、Tab、换行和连续空格。

证件照相纸按 mm / DPI 计算，不自动改打印规格；单边最多 8192px，桌面 3200 万 / 移动 1600 万总工作像素，排版检查另计单张缓冲，最多 200 张，放不下明确拒绝。人像抠图工作图最长边 2048px，模型只在点击后下载，支持取消。输出 PNG / JPEG 最多 100 MiB。

本地字体：1–8 个，单个 64 MiB、总计 128 MiB；压缩容器声明的单字体解压数据最多 128 MiB，批次桌面 256 MiB / 移动 128 MiB。仅预览且不能保证中断浏览器原生解码。显存估算不分配纹理，输入是安全正整数，用 BigInt 输出理论字节数，不伪设硬件规格上限。

GIF 编辑复用提取后的最多 200 帧 PNG，逐帧解码和编码，输入与输出、画布及量化空间共同检查，输出桌面 256 MiB / 移动 128 MiB；15 分钟保护，可取消，不自动缩图。延迟 0–655350ms，按 10ms 整数刻度存储，循环扩展 0–65535（单次播放不写循环扩展）。

BPM 解码支持最多 32 声道，并在创建采样接收器前将区间帧数乘以实际全部声道数，检查全站解码采样预算；不能只按最终选取的单声道缓冲评估解码工作量。

音频 BPM：源文件沿用 2 GiB，按选区流式解码，至少 5 秒；BPM 搜索 30–300，采样率 8–192 kHz。分析缓冲上限为 `audioSampleBudget() / 16`，即桌面 1200 万 / 手机或低内存 400 万单声道采样值，为解码与峰值计算预留空间；不是统一分钟数，也不是浏览器堆内存保证。估算 Worker 30 秒后终止，不自动缩短区间。浏览器信息：UA 最多 32768 字符，只接收单行，手动解析与当前环境检测分开；不读取高熵 Client Hints、不请求设备权限。详见 [范围与边界](bpm-browser-tools.md)。

重复文件检查：2–2000 个文件，按 2 MiB 分块哈希及字节确认，不增加整文件输入大小上限，单次任务沿用 15 分钟保护。PDF 转扫描件：200 MiB / 1000 页，复用 PDF 导出画布预算，编码图片合计与最终输出各为桌面 256 MiB / 移动 128 MiB；逐页嵌入完成后释放可释放的解码状态，并把 PDF 保留缓冲、对象预留与临时封装工作量纳入桌面 512 MiB / 移动 256 MiB 预算。这是工作量估算，不是完整浏览器堆测量；不自动降清晰度。详见 [工具边界](duplicate-scan-tools.md)。

GIF 帧提取与 XML 的详细范围见 [选型记录](gif-xml-tools.md)：GIF 单文件 100 MiB、最多读取 2000 帧 / 导出 200 帧，画布与累计像素帧预算共同检查；解码前 LZW 校验要求精确像素数和结束码，固定 4096 项字典，逐帧码预算为像素数 ×2+4096、全文件总码预算桌面 2 亿 / 移动 1 亿。PNG 总量桌面 256 MiB / 移动 128 MiB，另预留 ZIP 空间。XML 500 万字符、100 层、25 万节点，30 秒线程保护，只接收 UTF-8，不支持 DTD / 自定义实体。

新增路径、摘要和缓动工具的详细范围见 [选型与验证](json-digest-easing-tools.md)：JSON 500 万字符 / 100 层 / 25 万节点，路径 200 条且合计 32768 字符、输出 3200 万字符，任务线程 30 秒保护；文本摘要 200 万字符、HMAC 密钥最多 64 KiB（按实际字节），无原生硬取消保证；曲线 x 为 0～1、编辑器 y 为 -2～3，时长 100～10000ms，不自动播放。

全站输入与处理策略集中在 `app/lib/resource-limits.ts`。限额用于避免单次任务耗尽浏览器资源，不代表 Cloudflare 上传配额；本地处理工具不会因为导入大文件而上传原文件到服务器。

## 内存保护与交互

- 大量文件、单个大文件会先显示“继续导入／取消”，不直接按旧门槛拒绝；手机和低内存设备更早提示。
- 图片先检查可识别的格式头，超过 1 亿像素拒绝；大图显示估算的单份像素缓冲大小，再由用户确认是否按原尺寸处理。
- 需要像素缓冲的图像／贴图操作按预计工作空间检查：桌面 2 GiB、移动端／低内存设备 512 MiB。导入上限不等于每台设备均能处理对应原尺寸。
- 整段音频需要解码为浮点采样，桌面预算为 1.92 亿采样值，移动端／低内存设备为 6400 万；声道、采样率、已有片段都会计入。估算与实际解码结果分别检查。变速工具也检查预期输出采样量。
- 媒体输出按位置写入分块 Blob，支持容器回写文件头。桌面下载缓冲预算 1 GiB，移动端／低内存设备 512 MiB；超预算明确报错，不返回不完整文件。
- 文本、Unicode、PDF 等大列表每页 200 项。长时间本地文件和栅格 Worker 的超时调整为 15 分钟，仍可取消；OCR 为 10 分钟。

## 保留的约束

新增实用工具沿用本地处理原则：密码最长 256 字符、批量最多 1000 条；JWT 最多 10 万字符；正则测试文本最多 200 万字符，独立线程 5 秒后终止，最多列出 1000 个匹配。ICO 输入沿用现有图片限制，输出采用 ICO 标准内的 16–256px 尺寸。详细说明见 [实用工具选型](pc-tool-research.md)。

第二批的图片调色沿用图片输入、像素和栅格工作空间保护；1280px 预览不影响原尺寸导出。DPI 工具只改元数据、不解码像素，输入为 100 MB；支持 1–65535 DPI，超过 10 万结构段视作异常。视频取帧沿用 2 GB 输入，单次最多 200 张；实际输出预算为桌面 512 MiB、手机/低内存设备 256 MiB，不以源视频大小代替解码或输出预算。

第三批文本编解码输入为 200 万字符，拼音为 20 万字符；CSV / TSV / JSON 输入为 500 万字符、10 万行、1000 列、100 万单元格。三者不上传、不保存输入；输出上限 3200 万字符，界面仅预览前 5 万字符，复制和下载保留全部。表格预览单独限制为 101 行、20 列、每格 300 字符，不影响转换结果。图片转 PDF 支持 200 张、每张 100 MB、总计 1 GiB、每张 100 MP；按顺序解码和释放位图，累计嵌入工作量保护为桌面 512 MiB / 移动端 256 MiB，最终 PDF 上限 200 MiB。大批量建议手动选择 2048 / 4096px 或分批，绝不静默降低质量。

浏览器画布、WebGL 纹理尺寸、编码器支持、QR 容量、文件系统名称长度、日期合法范围，以及数学算法的支持范围，不能仅靠提高数字消除。视频倒放仍有 1 小时任务保护，GIF 仍有组合工作量保护。

服务器请求长度、允许的媒体域名、短链接频率限制、ZIP 路径与压缩炸弹保护、HTML 净化及 JSON 嵌套检查不因本次放宽而删除。Cloudflare 单个部署静态资源的限制也与用户本地文件大小无关。

处理限制与发布版本分别管理；调整限制不会自动修改版本号，部署与 GitHub 发布按明确请求执行。

## PDF 导出、图片网格与 YAML

- PDF 导出沿用 200 MiB / 1000 页输入，支持任意不重复页序。图片输出单边不超过 8192px，单页像素预算桌面 32 MP、移动端 16 MP；ZIP / 图片累计输出桌面 512 MiB、移动端 256 MiB。超预算明确要求降低 DPI 或缩小页码范围，不自动缩图。PDF 文字最多 3200 万字符，每页最多 25 万文字片段，不执行 OCR。
- 图片网格每张 100 MiB / 100 MP，行列各 1–20，合计最多 200 格；单格画布不超过 8192px。顺序编码、写入 ZIP 并释放画布，不同时持有全部解码切片；输出使用 512 / 256 MiB 设备预算。不可整除的边缘像素完整保留。
- YAML / JSON 输入 500 万字符，最多 100 层 / 25 万数据节点，别名展开计数 100，输出最多 3200 万字符；在独立可终止 Worker 中运行。只转换单文档、JSON 兼容数据；拒绝循环、未知标签、重复键、非有限数与不安全整数。
- 对比度工具只解析 3 / 6 位 HEX 和 0–100% 文字透明度，背景不透明。数值阈值判断不做四舍五入，结果不等于页面或组件完整符合 WCAG。

## Cron、文件识别、图片对比与视频裁剪

- Cron 表达式最多 500 字符，预览 1–50 次；起算时间必须为空或含偏移的 ISO 8601，不接受年份字段、@ 别名或 H 随机字段。只计算预览，不创建或执行任务；夏令时具体规则仍以实际调度平台为准。
- 文件类型识别每批 1–200 个，逐个仅读取前 64 KiB，不整文件加载，因此不设固定源文件大小上限。ZIP/GZIP 只检测容器头，不解压验证内部文件。结果不能替代病毒、完整性或内容校验。
- 图片差异沿用每张 100 MiB / 100 MP，单边 8192px；要求原尺寸完全一致。工作空间按 6 份 RGBA 缓冲估算，桌面 2 GiB、手机/低内存 512 MiB；输出 PNG 预算 512 / 256 MiB。仅预览缩至最长边 1280px，比较与下载不自动缩图。透明像素按白底视觉比较，差异率不是内容相似度。
- 视频裁剪沿用 2 GiB 源文件和分块输出桌面 1 GiB / 移动端 512 MiB 预算；用户可主动缩短区间、降低画质或分辨率。使用浏览器 WebCodecs 重新编码，仅主视频和可选主音轨，不保证无损或毫秒精确；音轨不可转换时明确报错，不静默删除声音。时间轴非零起点时禁用播放器取点，手动区间按首帧为 0 换算。

## 子网、网址与设计生成器

- IP 输入最多 200 字符；CIDR 额外允许前缀，不枚举整个网段。IPv6 用 BigInt 精确计算 128 位范围与数量；只接受严格四段十进制 IPv4 和无区域标识 IPv6，结果不等于可达性或地址分配建议。
- URL 输入和编码后结果最多 32768 字符、1000 个查询参数，每页显示 200 个参数。只支持 HTTP / HTTPS；不发请求、不开导航、不存草稿。参数编辑会按表单规则重新编码，可能影响签名；清理追踪和账户信息均须明确操作。
- 渐变支持 2–8 个严格递增色标，不支持重复位置硬切换；65 个常规采样点加原色标节点，预乘透明度后转为 sRGB，超色域通道裁切。PNG / SVG 单边 1–8192px，总像素桌面 32 MP / 手机或低内存 16 MP，不自动缩图；画布按两份像素缓冲检查，结束后释放。
- 阴影支持 1–6 层；偏移 ±200px、模糊 0–200px、扩展 ±100px、圆角 0–100px、不透明度 0–100%。预览裁切超出区域的阴影以避免页面溢出，CSS 导出不裁切；实际模糊由浏览器渲染，不能将脚本检查当作跨浏览器视觉一致性保证。

## 页码、裁切、素材提取与练习

- PDF 页码和裁切沿用 200 MiB / 1000 页输入、200 MiB 输出；范围按输入页序编号，不改变页面排序。可见区域取 MediaBox / CropBox 交集，支持 0 / 90 / 180 / 270 度；非标准 UserUnit 明确拒绝。预览只绘制一页并沿用 4 MP 保护。页码模板最多 120 字符，字号 6–48 pt、边距 2–50 mm；中文按需读取同源 Noto Sans SC 并嵌入子集，不接受用户字体或 Emoji。裁切仅设置 CropBox，隐藏内容仍在，不能当作脱敏；签名可能失效，须保留原件。
- PPTX 输入 200 MiB / 1000 页，ZIP 最多 2000 个条目，展开和输出预算为桌面 512 MiB、手机 / 低内存设备 256 MiB。单 XML 在解压前检查 16 MiB，解析预算 100 层 / 25 万节点，正文上限 3200 万字符；沿用 ZIP 路径、压缩比、CRC 与重复条目校验。不支持旧 PPT、宏格式、加密包、布局还原、OCR 或备注提取；DTD / 实体声明被拒绝，不获取外部资源。包内图片不执行或自动预览，下载保留原始字节，含 SVG 等文件时仍应自行检查。
- 图片颜色替换沿用 100 MiB / 100 MP、单边 8192px；估算 4 份 RGBA 工作空间（桌面 2 GiB / 手机或低内存 512 MiB）。1280px 仅缩略预览，不缩小下载；保留 alpha、完全透明像素不处理，PNG 不保留源元数据。RGB 颜色距离不是语义或区域分割，所有匹配位置均可能变化。
- 提词稿件 10 万字符，只在当前页面内存中；速度 5–200 px/s，字号 20–96px。单帧最多补走 100ms，避免后台回到前台突然跳过大量稿件；隐藏页面自动暂停。全屏取决于浏览器支持，不静默保存或上传稿件。
- 打字参考及输入最多 2 万 UTF-16 字符且 5000 字素，NFC / 换行规范化，30 / 60 / 120 秒。首次提交输入开始计时，中文组合期不计入正文；截止后不接受迟到输入。只渲染当前位置附近 300 个参考字素，准确率允许退格修正，WPM 以 5 个正确字符为一词；不是考试认证或防作弊系统，不保存成绩。

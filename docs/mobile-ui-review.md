# 手机端布局检查

## 范围与证据

检查目录中的 117 个工具入口及其本地 UI 导入链，共 231 个源码文件，覆盖 8 个分类。可运行 `node scripts/mobile-layout-inventory.mjs` 输出逐路由清单；这是源码覆盖清单，不是浏览器截图验收。

此为初始检查范围；随后加入的 4 项图片能力见 [图片工具补充](phototool-tools.md)，当前自动清单为 121 个工具、238 个相关源码文件。新增控件继续使用相同手机布局与取色器规则。

本轮用户截图显示渐变色生成器的色标标签被挤成逐字换行。此前浏览器检查没有获得许可，本轮已再次询问；在取得许可前不启动浏览器、Playwright 或 CDP，不声称已逐页验证手机显示。

## 已定位和处理的问题

| 文件 | 已确认的问题与影响 | 调整理由和处理 |
| --- | --- | --- |
| `app/styles/additional-utilities.css`、`app/globals.css` | 取色器 54px 规则与后加载的通用输入框 100% 规则优先级相同，后者获胜；同一行 HEX 标签被挤窄。渐变、阴影和颜色对比度复用此结构。 | 取色行改为 `minmax(0, 1fr) 54px` 网格，取色器使用更明确的作用域，保留 HEX 输入空间。回归检查规则优先级，而非仅检查存在 54px 字样。 |
| `app/styles/additional-utilities.css` | 色标和 URL 参数分组的边框、内边距被通用 fieldset 重置覆盖，分组结构不清楚。 | 明确控件分组作用域，恢复边框与间距；窄屏色标间距为 10px。 |
| `app/components/scientific-tool.tsx` | 矩阵列数可增加，每格至少 44px，加上列间距可能超过手机容器；原来没有独立的横向滚动区域。 | 为矩阵格添加可聚焦、有名称的滚动容器，保留可编辑单元尺寸，不压缩成无法输入的小格子。 |
| `app/globals.css` 的共享布局、`app/styles/mobile-tools.css` | 标题与操作区、输入与按钮为不换行的 flex 结构；工作台多列表格的正文允许在任意字符换行。窄屏无法稳定保证标签和列的阅读宽度。 | 手机标题和内联控件允许换行，表头保持完整词组、单元保留阅读宽度，在原有表格容器内滚动；没有隐藏整页溢出。 |
| `app/styles/mobile-tools.css`、`app/layout.tsx` | 旧控件字号、面板间距和窄屏两列表单规则分散，缺乏统一的手机收口。 | 手机规则在共享样式后加载，工具页标题、面板和间距更紧凑；普通输入 16px，主要操作区至少 44px。480px 以下工作台字段改为单列，详情改为标签在上、数值在下。 |

## 保留的行为

- 工具访问路径、处理逻辑、下载格式、主题配色不变。
- 不改首页、收藏、桌面工具卡片或箭头动画。
- 主要布局收口仅在 680px 以下；表单进一步单列仅在 480px 以下。
- 桌面仅同步修复取色控件原有冲突和矩阵溢出容器，不重新设计桌面布局。
- 宽矩阵、表格、Unity 树和键盘布局可以在各自容器内滚动，不通过隐藏页面内容消除溢出。

## 验证与待验收

新增回归覆盖源码入口清单、CSS 作用域与优先级、矩阵滚动语义、手机与桌面 UA 下全部工具的服务端页面结构，以及构建产物中的手机样式。UA 和 CSS 静态检查不计算真实排版，不能证明所有页面均无视觉问题。

初始布局检查的生产构建、类型检查、完整 lint 及新增文件专项 lint 通过；当时全量 789 项测试通过。后续统一发布内容见 [v1.3.0](releases/v1.3.0.md)。

待浏览器许可后，按 320、360、390、430、768 和 1440px 检查：页面级横向溢出、短标签逐字换行、遮挡和控件大小；渐变 8 色标、阴影 6 层、大矩阵、长文件名、多列表格、上传后的编辑状态及深色主题也需实测。真实触摸、系统字体放大、软键盘和 iOS 输入行为仍需实机确认。

# 多功能工具箱 v1.3.0

## 新增

- 图片圆角与边框、画布与纯色图、双色调和锐化。
- 贴图显存估算、证件照制作与排版、本地字体预览。
- GIF 拆帧与编辑：完整帧提取、时间轴、帧序、延迟与循环设置。
- PDF 转扫描件、XML 格式化与校验、重复文件检查。
- 音频 BPM 分析、浏览器信息与能力检测。

## 优化与修复

- 图片 OCR 增加 PaddleOCR，支持裁剪、旋转和放大；减少中文多余空格，保留原始结果与兼容引擎。
- 手机工具页收紧表单间距，按钮自动换行，宽表格与矩阵独立滚动。
- 修复取色器挤压标签、色标与参数分组边界不清的问题。
- 加强 GIF 压缩数据校验、PDF 扫描件内存保护及取消后的资源清理。
- 修复构建依赖安全告警，浏览器图像引擎不再重复带入服务端包。

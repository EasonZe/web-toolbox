# 多功能工具箱 v1.1.0

## 新增

- 密码与 UUID、正则测试、JWT 解析、条形码、节拍器和 ICO 图标制作。
- 单位换算、图片调色、DPI 修改、视频截图与批量取帧。
- 文本编解码、汉字转拼音、CSV / TSV / JSON 转换和图片转 PDF。

## 优化与修复

- Unity 资源包采用目录树，右侧集中显示预览与操作，移除精灵图工具。
- 调整大文件与批量处理限制，减少媒体处理中的峰值内存。
- 修复搜索结果隐藏、汇率旧数据和资源预览清理问题。
- 优化视频解析缓存、并发与超时处理，更新依赖安全补丁。

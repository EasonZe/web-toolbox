# 多功能工具箱 v1.1.0

发布时间：2026-10-23。

[在线使用](https://tool.easonzhan.xyz/) · [处理范围](../resource-limits.md) · [工具选型](../pc-tool-research.md)

## 新增 14 个工具

- 密码与 UUID 生成、正则表达式测试、JWT 解析、条形码生成。
- 节拍器、ICO 图标制作、单位换算。
- 图片调色与滤镜、图片 DPI 修改、视频截图与批量取帧。
- 文本编码与解码、汉字转拼音、CSV / TSV / JSON 表格转换、图片转 PDF。

所有新增工具在浏览器本地处理，接入现有分类、搜索、收藏与站点地图。GitHub 选型与第三方许可证已补全，保留原有界面、工具路径和部署方式。

## 优化与修复

- Unity 资源包预览使用目录树，资源预览与紧凑操作区位于右侧，移除精灵图切割与合成工具。
- 修复同数量搜索切换后卡片隐藏、汇率切换套用旧数据及资源预览清理问题。
- 重任务按需加载后台引擎，增加可取消处理、内存预算和输入检查，不静默截断结果或降低导出质量。
- 视频解析 Workers 的缓存、并发合并、超时和回退优化收录于仓库；此次发布不重复部署 API Workers。
- Next.js 16.4.2、DOMPurify 3.4.17、Vite 8.1.6 安全补丁及回归约束。
- 网站、页脚与依赖锁版本统一为 1.1.0，三种语言 README 更新。

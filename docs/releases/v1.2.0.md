# 多功能工具箱 v1.2.0

## 新增

- 文档：PDF 转图片与文字、加页码、裁剪，以及 PPTX 图片与正文提取。
- 图片与设计：网格切分、颜色替换、差异对比、渐变色、CSS 阴影与缓动曲线。
- 开发：YAML / JSON 互转、JSON 路径提取、文本哈希与 HMAC、Cron 预览、文件类型识别、子网计算与 URL 参数编辑。
- 实用：视频裁剪、颜色对比度检查、提词器和打字速度测试。

## 优化与修复

- 图片与 PDF 结果可直接交给后续工具处理，保留原下载入口。
- 图片压缩和格式转换支持停止、保留结果并继续未完成项。
- PDF 切页复用文档，减少重复解析；完善后台任务取消与资源清理。
- 修复退出后继续处理、清空后旧文件回填和重复导入。
- 简化三语 README，统一整理历史版本说明。

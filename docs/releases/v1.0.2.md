# 多功能工具箱 v1.0.2

## 新增

- 文档：PDF 页面管理、文本对比、OCR、JSON、Markdown、字幕转换。
- 文件：批量重命名、ZIP 打包解压、EXIF 查看清除、Unicode 检查。
- 媒体：音频裁剪拼接、时间戳转换、无缝贴图、通道打包、全景预览、高度转法线。

## 优化

- 调整大文件与批量处理限制，支持取消和结果分页。
- 完善 OCR 加载、ZIP 校验、Markdown 净化与导出文件名。
- 移除“其他服务”分类和网易云音乐第三方解析入口。

## 音频 BPM

- 手动选择文件，设置区间、BPM 搜索范围与首 / 第二 / 前双声道混合；不播放、不修改或上传音频。
- 使用 Mediabunny 的 Blob 读取与区间采样，不先整文件解码。格式及编码支持取决于浏览器，不能仅凭扩展名保证可用。
- 采样按时间戳放入所选区间，合法的时间戳间隙填零以保留原时间轴，不将分隔的音频块直接拼接。填零不代表恢复缺失的录音内容。
- 预处理按 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/) 的二阶低通公式独立实现，截止频率 240 Hz，取包络并归一化。该处理不是人声分离，也不能保证所有音乐都有可识别的节奏。
- 仅导入 `web-audio-beat-detector-worker/build/es2019/helpers/guess.js`，不导入根入口、不注册其全局 singleton Worker；计算在本项目拥有并可终止的任务 Worker 内执行。升级引擎时必须复核深入口及行为。
- 上游峰值扫描按 `sampleRate / 4` 步进，11.025 / 22.05 kHz 会产生小数数组索引、无法继续寻找峰值。适配层在低通后对这类采样率线性重采样到相邻的较低 4 倍数（11024 / 22048 Hz），保持时间轴，不伪造采样率或拒绝常见音频；源文件及结果中的原始采样率不变。
- 源文件上限 2 GiB，区间至少 5 秒；BPM 范围 30–300，采样率 8–192 kHz。单声道分析缓冲预算为 `audioSampleBudget() / 16`：桌面 1200 万、手机或低内存 400 万采样值；超限提示缩短区间，不静默截取。解码器和临时数组另有开销，此预算不等于实际峰值堆内存。
- 分析线程 30 秒保护，解码沿用本地任务取消与总超时；结束、取消、清空和卸载时清理媒体输入及 Worker。
- 解码支持最多 32 声道，并在创建采样接收器前检查 `区间帧数 × 全部声道数` 不超过全站解码采样预算；虽只分析指定声道，不能忽略解码器实际读取全声道的工作量。
- 报告提供 BPM、未取整估算值、相对分析区间的节拍相位及半速 / 倍速候选，不生成逐拍标注或检测曲速变化。相位不是整首歌的首拍；候选不是置信度。静音、语音、弱鼓点、变速音乐及反相混音可能无结果或误判，需要人工核对。

## 浏览器信息

- UA 解析支持手动粘贴 / 导入，也可明确点击读取当前 UA；页面打开不自动读取。最多 32768 字符，不接受控制字符和换行，不保存草稿。
- UA 可以被伪造，系统和设备信息可能缩减或隐藏；iPad 桌面模式可能报告 macOS。未知字段留空，不补猜测值，也不将结果用于身份或权限判断。
- API 检测只检查当前环境暴露状态，和粘贴 UA 的解析分开，报告分别导出；不能通过一条 UA 推断另一个设备的实际能力。
- 不启动音频、媒体、编解码器或文件选择器，不调用设备权限接口，不读取高熵 Client Hints、硬件 ID 或 Canvas 指纹，不发外部请求。
- “存在”不代表功能可用；安全上下文、权限、编码器、硬件及策略仍可能限制调用。本工具不宣称完成实际编解码或跨浏览器兼容性测试。

新增回归包含真实 Mediabunny 立体声 WAV 选区解码、三种声道处理、取消与资源关闭；实际生产 Worker 对 100 / 120 / 160 BPM 合成信号估算，并覆盖 8 / 11.025 / 22.05 / 44.1 / 48 kHz。合成信号不代表真实音乐准确率。UA 使用真实 Bowser 解析，API 暴露检查验证不构造或调用敏感 API；Hook、生产 SSR 与 390px / 1440px 首页四种布局的搜索收藏回归通过。

框架安全修复另以实际官方插件、本地字体 / WASM / SVG 生成 PNG；无外部资源请求。Node SSR 测试只为空的可选 Cloudflare tracing 适配平台模块，不模拟绑定或代替真实 workerd。首次 Lint 因旧的 `outputs/` 打包产物耗尽 Node 堆，已仅排除该生成目录，未扩大内存或屏蔽源代码检查。

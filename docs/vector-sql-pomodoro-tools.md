# SVG 矢量化、SQL 格式化与番茄专注钟

## 选型

| 工具 | 来源 | 集成方式 |
| --- | --- | --- |
| 图片转 SVG `/image-vectorizer` | [ImageTracerJS](https://github.com/jankovicsandras/imagetracerjs) 1.2.6，Unlicense | 复用像素描摹 API，在专用 Worker 中生成真实路径；不把原图嵌入 SVG |
| SQL 格式化 `/sql-formatter` | [sql-formatter](https://github.com/sql-formatter-org/sql-formatter) 15.9.0、[Nearley](https://github.com/kach/nearley) 2.20.1，MIT | 文件 Worker 内按需加载格式化器，页面只负责输入、参数和结果 |
| 番茄专注钟 `/pomodoro` | 功能参考 [Pomotroid](https://github.com/Splode/pomotroid)，MIT | 工作 / 短休 / 长休状态机独立实现，复用浏览器计时与 Web Audio，不引入 Electron 或新依赖 |

既有图片线条重绘导出 PNG，倒计时器处理单轮时长或目标时间；新增工具分别补充彩色 SVG 和专注休息轮次。没有复制 PC-TOOL 或 ToolKnit 的源码、界面和素材。

## 处理边界

- SVG：接收静态栅格图片。最长处理边由用户选择 512、1024 或 2048px，不放大小图；显示实际处理尺寸。颜色数量 2–32，可调整曲线拟合和小斑点过滤。描摹是近似重建，不能恢复原始矢量或照片细节。生成结果按安全规则检查，仅作为 Blob 图片预览，不插入页面 HTML。
- SVG 的工作量随像素、颜色和轮廓复杂度增加。超时或超出路径、片段与输出大小预算时停止，用户可取消或调整参数后重试，不静默降低所选尺寸。
- SQL：支持 20 种方言、2 / 4 空格缩进、关键词大小写；保留标识符、字符串与占位符。最多 500 万字符，结果沿用全站文本预算。任务超过 30 秒停止，输入不丢弃，修改输入或参数会取消旧任务。
- SQL 格式化不是数据库完整语法校验，不连接数据库、不执行查询、不检查业务逻辑。引擎不支持存储过程和自定义分隔符；解析错误保留引擎给出的定位信息，错误回显限制长度。
- 番茄钟默认专注 25 分钟、短休 5 分钟、长休 15 分钟，每 4 轮专注后长休。按绝对截止时间校正剩余时间，阶段结束后等待开始下一阶段；后台停留不会补记多轮专注，跳过不计完成。网页关闭、浏览器暂停或设备休眠时不保证声音提醒。

三项工具均在本地处理，不上传输入，也不保存草稿。路由、首页分类、搜索、收藏和主题沿用现有实现。

## 依赖与验证

新增两个精确版本的直接依赖。ImageTracerJS、sql-formatter 和实际使用的 Nearley 运行时的原始许可随构建复制到 `public/vendor-licenses/`。argparse 以及 Nearley 的编译 / 命令行辅助模块不进入格式化调用路径，不把这些模块误列为新的浏览器引擎。

回归应覆盖 SVG 路径、透明区域与空洞的真实栅格结果，SQL 多方言、字符串、占位符、错误及取消，以及番茄钟暂停、跳过、轮次、后台恢复和清理。生产构建后的 Worker 和页面初始渲染需单独检查。源码布局声明与 Node 图像测试不等于桌面 / 手机的实机视觉验收；本记录不宣称浏览器截图或触控验证已完成。

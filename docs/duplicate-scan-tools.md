# 重复文件检查与 PDF 转扫描件

## 来源与选型

2026-10-27 重新核对 [ToolKnit Desktop](https://github.com/ZihangDong/toolknit-desktop#完整工具目录) 与 [PC-TOOL](https://github.com/Team-YM/pc-tool)。前者目录包含重复文件清理、PDF 转扫描件，选取适合浏览器的只读检查和页面栅格化；后者列出的图片旋转 / 翻转已由本项目图片裁剪提供，其余主要功能也已有对应入口，本期不重复增加工具。

只参考公开功能说明，不复制界面、代码、素材或受限 PDF-to-Word 引擎。ToolKnit 的 [NOTICE](https://github.com/ZihangDong/toolknit-desktop/blob/main/NOTICE) 区分 PolyForm Noncommercial 作者代码、独立引擎及第三方依赖，公开可读不代表能整体移植；PC-TOOL 未见可据以复制整站的根许可证。本项目继续使用 MIT。

## 重复文件的范围

- 2–2000 个手动选择的文件，可多选、拖入或选择目录；目录选择依赖浏览器支持，只取得所选目录内的相对路径，不读取电脑绝对路径。
- 大小不同直接排除，同尺寸先 SHA-256，再逐字节确认；改名不影响判断，同名不同内容不混组。空文件可以分组，不是图片相似度或音频指纹识别。
- 哈希和字节确认均按 2 MiB 切片顺序读取，不整文件 `arrayBuffer`。输入文件不设新字节上限；沿用单次本地任务 15 分钟保护，超时可缩小批次重试。
- 只读结果与 JSON 报告，不访问系统目录、默认指定保留项、写入源文件、移动到回收站或执行删除。报告含名称、所选目录内相对路径、大小、SHA-256 和分组，下载由用户主动触发。
- 每页 20 组，单组预览 50 项，完整报告不截断。统计是相同内容的冗余副本字节量，不是实际可释放磁盘空间（不推测硬链接、稀疏文件或文件系统压缩）。

## PDF 的范围

- 200 MiB / 1000 页，支持范围与页序。复用 PDF 图片导出的 72 / 144 / 216 / 300 DPI 与画布预算，逐页处理，超预算报错，不静默降清晰度。
- 新 PDF 仅包含绘制后的页面图片；原页可见尺寸、CropBox 与旋转反映在新页面宽高和画面中，不复制原文档的文字层、JavaScript、附件、链接、表单或批注层，不保留原签名。
- 原彩、灰度、黑白阈值，白色页面背景；灰度按加权 sRGB 分量估算，不承诺色彩管理或印刷色度精度。不模拟纸张纹理，不是安全脱敏、防复制或真实性证明；结果仍可被 OCR 识别。
- JPEG 可调质量 / PNG 无损；JPEG 黑白效果仍可能有压缩灰边，纯黑白像素请用 PNG。PDF 栅格化可能增大体积，不宣称能压缩所有文件。
- 编码图片合计及最终 PDF 各自限制为桌面 256 MiB / 移动设备 128 MiB，留出封装与像素空间；这是工作预算，不是对浏览器峰值内存的保证。只保留首个输出页缩略预览。
- 复用渲染器增加可选的编码前过滤回调，原 PDF 图片导出不传回调时行为不变。灰度 / 黑白像素移交后台处理，完成后取回编码；取消终止像素线程、取消绘制、释放画布与加载文档。
